# Glossary

## Order
A customer order that already exists in the orders system.

## Order book
The set of existing orders that support leads need to understand.

## Support lead
A support user who needs a quick picture of orders and order totals.

## Order status
The current state of an order. The named statuses are placed, shipped, delivered and cancelled.

## Non-cancelled total value
The total value, in cents, of all orders that are not cancelled.

## Customer filter
A way to return only orders for a named customer.

## Customer name
The customer value used to match orders for filtering.
