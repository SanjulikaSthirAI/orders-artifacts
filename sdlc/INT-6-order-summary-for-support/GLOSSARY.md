# Glossary

## Order
A customer order that already exists in the orders system.

## Order book
The set of existing orders that support leads need to understand.

## Order book summary
A read-only snapshot of the Order book containing counts by Order status and the Non-cancelled total value.

## Support lead
A support user who needs a quick picture of orders and order totals.

## Order status
The current state of an order. The named statuses are placed, shipped, delivered and cancelled.

## Order status filter
A way to return only orders with a requested Order status.

## Non-cancelled total value
The total value, in cents, of all orders that are not cancelled.

## Stored value
The order value in cents already held by the orders system for an Order.

## Customer filter
A way to return only orders for a named customer.

## Customer name
The customer value used to match orders for filtering.

## Returned Orders
The Orders included in an Order book API response after any requested filters are applied.

## API capability
A behaviour made available to API callers through an API operation.

## Response
The data returned to an API caller for a request.
